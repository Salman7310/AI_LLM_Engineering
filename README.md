# AI / LLM Engineering

Hands-on projects and exercises applying large language models to practical tools, built while going deeper into LLM engineering alongside my mobile work.

## What's here

**Company Brochure Generator** — Scrapes a company's website and uses an LLM to generate a structured marketing brochure from the extracted content (prompt design, content parsing, and structured output generation).

**Week1_exercise-tutor.ipynb** — A technical tutor built on Groq's fast inference API, answering technical questions with streamed, explained responses.

## Why

As a senior mobile engineer, I've been extending my full-stack and AI toolset — this repo tracks the applied side of that: real prompt engineering, API integration, and small end-to-end tools rather than just tutorials.

## Stack

Python, Jupyter, OpenAI/Groq APIs, prompt engineering, web scraping.

More projects added as I go.
